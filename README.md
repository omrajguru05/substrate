# Substrate Labs — Agent Skill

Official design system and brand language skill for **Substrate Labs** (`substrates.in`).

Combines the dark-field laboratory identity, specimen canvas doctrine, 4-tier container architecture, and the complete 54 chapters of Substrate Brand Language.

## Installation

Install using the `skills` CLI:

```bash
npx skills add omrajguru05/substrate
```

Or install with specific agent targets:

```bash
npx skills add omrajguru05/substrate --agent claude-code cursor antigravity
```

## Structure

- `SKILL.md`: The unified master skill for coding and writing agents.
- `references/design-system.md`: Full laboratory design tokens, 4-tier containers, canvas specimen architecture, and 18 rich article components.
- `references/brand-language.md`: Complete 54-chapter Substrate Brand Language manual.

## Core Non-Negotiables

- **The ground is pure black (`#000000`).** No light mode, no dim mode, no toggle.
- **Red is stimulus (`#B51F2E`); Green is response (`#39D353`).** No decorative color, no fifth hue (no blue, no purple).
- **The DOM is still; life happens in the canvas.** Specimen preparations carry all motion.
- **Write for use, not for features.** Put the useful human meaning first.
- **Literal interface copy.** Interfaces describe what is actually happening.
- **Evidence before adjectives.** Never rely on empty praise ("revolutionary", "powerful", "seamless").
